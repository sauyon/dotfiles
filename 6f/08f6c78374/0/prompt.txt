## Non-negotiables from the scope phase

- **The corpus never enters the repo.** Raw caches to `~/.local/share/svalboard-freq/`; only
  per-1000-character aggregates go to the committed `freq.json`. This repo is public and the
  corpus carries internal Modular hostnames. 2-gram and 3-gram files are **not** safe to
  commit — a 3-gram file leaks substrings.
- **Do not "fix" `config/keyboard/sval.yml` to match `build.py`'s `CUP_XY`.** They are a
  relabeling of the same 40 switches; the key costs in `config/evaluation/sval.yml` were
  fitted to sval.yml's coordinates.
- **Thumbs are frozen.** Their layout is argued from hardware constraints the optimizer
  cannot model.
- **Report the delta.** Every run evaluates the current layout under the same config and
  corpus so the output is a comparison, not an oracle.
