  ## 2. Design and trust argument
  **Chosen: a signed binary cache on disk (`file://`), shared by the privileged runner's jobs. Not a persistent `/nix`.**
  - A new `nixCache` values block, on only in `values-privileged.yaml`, mounts the hostPath `/var/lib/forgejo-runner-nix-cache` (fujiwara NVMe) into the dind sidecar at `/nix-cache`.
  - `/nix-cache` becomes the runner's only `container.valid_volumes` entry, so a workflow can bind-mount it and nothing else.
  - Jobs list it as the first substituter and `nix copy` the signed paths of their closure into it after a build.
  
  **Why not a persistent `/nix`:** nix never re-checks a path that is already in its own store. Every job on this runner is privileged, so one job could swap a file in, say, glibc. Later builds would link against it and push the result to attic, and every workstation would install it. Mounting over `/nix` would also freeze the nix binary from the image.
  
  **Why the cache is safe to share:** nix checks it on read. `require-sigs` is on and the URL has no `trusted=1`. Each narinfo must carry a signature from the cache.nixos.org or `kube:` key; the signature covers the store path, NAR hash, size and references; the NAR is checked against that hash. I tested this in the pinned job image (nix 2.34.8) and on the host:
  
  | What was in the cache | Result |
  | --- | --- |
  | Signed path | substituted from the cache |
  | Unsigned path | ignored |
  | Signed narinfo with its NAR swapped | hash mismatch, fell through to cache.nixos.org |
  | Unsigned path given another path's signature | rejected |
  
  - The worst a writer can do is delete or corrupt entries (the run gets slower), serve an older validly signed path (harmless), or fill the disk.
  - No secrets go into the cache. Only signed paths are copied, which already exist in cache.nixos.org or attic `kube`, and every current privileged consumer already holds a token that can pull `kube`. Paths built inside the job, where the private input ends up, are never copied.

  - `mountPath` is validated: a single top-level directory, no glob, not `/data` (the runner's registration token), `/sock` (the Docker API), `/nix`, or any other directory dind already has.
